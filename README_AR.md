# قاعدة بيانات اسكرينات Gomla Store

هذا مشروع ويب كامل بسيط لإدارة أسماء الاسكرينات وتوافقاتها، بواجهة عربية RTL وقاعدة بيانات SQLite.

## التشغيل
1. ثبّت Python 3.10+.
2. داخل المجلد نفّذ: `pip install -r requirements.txt`
3. شغّل: `python app.py`
4. افتح: `http://127.0.0.1:5050`

## إدخال بيانات الموقع الأصلي
تم تصميم الاستيراد على JSON حتى لا يتم اختراع أو تخمين أي اسم. الصيغة:

```json
[
  {
    "screen_name": "الاسم كما هو في المصدر",
    "brand": "الماركة",
    "compatible_models": ["الجهاز 1", "الجهاز 2"],
    "notes": "ملاحظات المصدر فقط"
  }
]
```

يوجد أيضًا تصدير CSV، وإضافة وتعديل وحذف يدوي.

ملاحظة: المصدر `https://stock.amigogascreen.com/` ظهر كواجهة نظام باسم GadgetMaxSmartShelf، لكن محتوى قاعدة البيانات لم يكن مكشوفًا في الصفحة العامة التي أمكن الوصول إليها أثناء التنفيذ؛ لذلك المشروع لا يحتوي أسماء مخمّنة.
